# PBD สแกนเข้างานนอกพื้นที่ (LIFF)

หน้าเว็บสแกนใบหน้าพนักงานด้วยมือถือหัวหน้าทีม ใช้ตอนออกแวน — เปิดผ่าน LINE (LIFF)

- จดจำใบหน้าในเครื่อง (face-api.js) เทียบกับรูปลงทะเบียน + รูปสแกนล่าสุดในระบบ yunatt
- ส่งผล (รหัส เวลา GPS รูป) ไปที่ Google Apps Script "Line-log dashboard" → แท็บ "สแกนนอกพื้นที่"
- ไม่มีสัญญาณ: เก็บไว้ในเครื่องแล้วส่งให้เองเมื่อมีสัญญาณ (ใช้เวลาที่สแกนจริง)

ตั้งค่า: แก้ `config.js` (LIFF_ID, GAS_URL)
ไฟล์นี้ไม่มีข้อมูลพนักงาน/รูปใบหน้า — ข้อมูลทั้งหมดอยู่ใน Google Drive/Sheets ของบริษัท
